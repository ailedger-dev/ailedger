# Contributing to AILedger

Thanks for your interest in contributing.

## License and the CLA

AILedger is dual-licensed: the public source is under the **GNU AGPLv3** (see
[LICENSE](LICENSE)), and a separate **commercial license** is offered to
organizations that cannot accept the AGPL copyleft obligations. Contact
`ops@jvholdings.co` for the commercial license.

For this dual-licensing model to hold, the project must own sufficient rights in
every contribution. **Every contributor must agree to the Contributor License
Agreement ([CLA.md](CLA.md)) before their pull request can be merged.**

- **Individuals:** the CLA assistant bot will comment on your first pull request
  and ask you to accept. Reply as instructed; it records your acceptance.
- **Companies:** if you are contributing on behalf of an employer, have an
  authorized signer email `ops@jvholdings.co` to execute a Corporate CLA before
  your employees open pull requests.

The CLA in this repo is currently a **DRAFT pending legal review**; it will be
finalized before contributions are accepted at scale.

## Pull requests

1. Open an issue first for anything non-trivial, so the approach can be agreed
   before you invest time.
2. Keep PRs focused and small where possible.
3. Make sure existing tests pass and add tests for new behavior.
4. Confirm the CLA checkbox in the PR template.

## Reporting security issues

Do not open a public issue for security vulnerabilities. Email
`ops@jvholdings.co` directly.
