# ADR-016 — Hedera HCS spike: measurements before the rails (Phase 0)

Status: **in progress** — instruments built; live testnet run pending operator
account provisioning. This ADR becomes the go/no-go record for building the
HCS-based evidence rails.

## Context

We are evaluating Hedera Consensus Service as the tamper-evidence substrate
for AILedger's evidence records (per-tenant topics; consensus timestamp +
sequence number + SHA-384 running hash as the ordering/integrity authority;
mirror nodes as the operator-independent read layer). Four facts the public
docs do not state must be measured, and two procedures must be rehearsed,
before committing to the design.

## Instruments (this change)

- **JCS parity harness** — `testdata/jcs-golden-vectors.json`, generated by
  `sdk/test/generate-jcs-vectors.mjs` from the production `canonicalize`
  package; enforced by `sdk/test/jcs-vectors.spec.ts` (TypeScript) and
  `cli/tests/test_canonical.py` against the new pure-stdlib
  `cli/src/ailedger_cli/canonical.py`. Extends the jcs-canary
  (threat model §6.8) from one vector to a corpus, and gives Python
  verification a byte-parity contract with TypeScript production hashing.
  Includes the two divergence traps: UTF-16 code-unit key ordering and
  ECMAScript number formatting.
- **Spike script** — `proxy/scripts/spike-hcs.mts`
  (`lifecycle` / `mirror-dump` / `burst` / `rotate`), Node ≥23, throwaway keys
  under `~/.secrets/hedera-spike/` (0600).
- **Running-hash layout detector** — `cli/src/ailedger_cli/runninghash.py`.
  The v3 running-hash preimage layout is not documented; the module implements
  the candidate layouts (payer-id included/excluded × nanos int32/int64) and
  detects which matches live mirror data.

## Procedure for the live run

```
source ~/.secrets/hedera-testnet.env   # HEDERA_OPERATOR_ID / HEDERA_OPERATOR_KEY
cd proxy
node scripts/spike-hcs.mts lifecycle
node scripts/spike-hcs.mts burst <topicId> 25 700
node scripts/spike-hcs.mts mirror-dump <topicId> /tmp/hcs-dump.json
cd ../cli && PYTHONPATH=src python3 -m ailedger_cli.runninghash /tmp/hcs-dump.json
cd ../proxy && node scripts/spike-hcs.mts rotate <topicId>
```
